## 校验规则说明

### 大小规则
- **大**: 和值 ≥ 14 (14, 15, 16, ..., 27)
- **小**: 和值 ≤ 13 (0, 1, 2, ..., 13)

### 单双规则
- **单**: 和值为奇数 (1, 3, 5, ..., 27)
- **双**: 和值为偶数 (0, 2, 4, ..., 26)

### 形态规则
- **豹子**: 三码相同 (如 555)
- **组三**: 有 2 个数字相同 (如 383)
- **组六**: 3 个数字都不同 (如 358)

### 跨度计算
- **跨度** = 最大数 - 最小数
- 示例：358 的跨度 = 8 - 3 = 5

### 和值计算
- **和值** = 百位 + 十位 + 个位
- 示例：358 的和值 = 3 + 5 + 8 = 16
